🧩 Petualangan Pseudocode (kode semu)

Informatika Kelas 8 (Fase D) — Kurikulum Merdeka

Di game ini kamu akan membaca dan menelusuri pseudocode (kode semu) baris demi baris, membedakan Syntax Error (kesalahan aturan penulisan) dengan Logical Error (kesalahan logika berpikir), lalu menemukan Bug (kesalahan pada program) memakai teknik Tracing / Desk-Checking (menelusuri nilai variabel baris demi baris).

Ada 3 level: 🟢 Pemula, 🟡 Menengah, dan 🔴 Tantangan. Kalau salah, tidak apa-apa — kamu boleh mencoba lagi dan memakai tombol Petunjuk.

Progresmu tersimpan otomatis di browser ini saja (localStorage). Tidak ada data yang dikirim ke internet.

📖 Kamus Istilah

Istilah bahasa Inggris selalu ditampilkan bersama artinya dalam bahasa Indonesia, supaya kamu otomatis terbiasa dengan istilah aslinya.

📘 Contoh & Tutorial (tidak dinilai)

Baca dulu tiga contoh ini supaya kamu paham cara kerja game. Setelah siap, kembali ke Peta Level.

Contoh A — Menghitung rata-rata

MULAI
  INPUT nilai1, nilai2, nilai3
  total = nilai1 + nilai2 + nilai3
  rata_rata = total / 3
  TAMPILKAN rata_rata
SELESAI

Uji dengan nilai1 = 85, nilai2 = 90, nilai3 = 80 → total = 255, lalu rata_rata = 255 / 3 = 85. Hasil ini benar.

Contoh B — Menentukan kelulusan (KKM = 75)

MULAI
  INPUT nilai
  JIKA nilai >= 75 MAKA
    TAMPILKAN "TUNTAS"
  LAINNYA
    TAMPILKAN "BELUM TUNTAS"
SELESAI

Kalau nilai = 80, maka 80 >= 75 benar, sehingga Output (hasil yang ditampilkan) adalah "TUNTAS". Kalau nilai = 60, Output-nya "BELUM TUNTAS".

Contoh C — Kasus debugging (cara mengisi tabel Tracing / Desk-Checking)

MULAI
  INPUT nilai_tugas, nilai_ulangan
  nilai_akhir = nilai_tugas + nilai_ulangan / 2
  TAMPILKAN nilai_akhir
SELESAI

Uji dengan nilai_tugas = 80 dan nilai_ulangan = 90. Tabel penelusurannya:

Baris nilai_tugas nilai_ulangan nilai_akhir
INPUT8090—
nilai_akhir = nilai_tugas + nilai_ulangan / 2809080 + 45 = 125
TAMPILKAN nilai_akhir8090125

Hasil program 125 itu salah, karena pembagian dihitung lebih dulu (90 / 2 = 45) sebelum penjumlahan. Ini contoh Logical Error (kesalahan logika berpikir) — tulisannya rapi, tapi maksudnya keliru.

Perbaikan yang benar: nilai_akhir = (nilai_tugas + nilai_ulangan) / 2 → (80 + 90) / 2 = 85.

🟢 Level 1 — Pemula

Skor: 0 / 100

Soal

Tulis pseudocode (kode semu) untuk menentukan bilangan genap atau ganjil dari sebuah angka yang di-Input (data yang dimasukkan).

Struktur yang harus ada: MULAI → INPUT → pengecekan sisa bagi 2 (mod/sisa) → percabangan JIKA–LAINNYA → OUTPUT (hasil yang ditampilkan) "Genap" / "Ganjil" → SELESAI.

💡 Petunjuk:

Sebuah bilangan disebut genap jika sisanya 0 ketika dibagi 2. Di pseudocode kamu bisa menulis sisa = angka mod 2 (atau angka % 2), lalu periksa JIKA sisa = 0 MAKA TAMPILKAN "Genap" LAINNYA TAMPILKAN "Ganjil".

📄 Lihat contoh jawaban benar 
MULAI
  INPUT angka
  sisa = angka mod 2
  JIKA sisa = 0 MAKA
    TAMPILKAN "Genap"
  LAINNYA
    TAMPILKAN "Ganjil"
SELESAI

🟡 Level 2 — Menengah

Skor: 0 / 100

Soal

Perhatikan pseudocode berikut. Ada satu Logical Error (kesalahan logika berpikir) di dalamnya.

Uji dengan nilai_uts = 80 dan nilai_uas = 90. Isi tabel Tracing / Desk-Checking (menelusuri nilai variabel baris demi baris) dulu, baru tentukan baris yang salah. 

MULAI
  INPUT nilai_uts, nilai_uas
  nilai_akhir = nilai_uts * 0.4 + nilai_uas * 0.4
  TAMPILKAN nilai_akhir
SELESAI

💡 Petunjuk:

Jumlah semua bobot penilaian seharusnya 100%.

2️⃣ Temukan Bug (kesalahan pada program)

Pilih baris pseudocode mana yang mengandung Logical Error (kesalahan logika berpikir):

📄 Lihat kunci jawaban Level 2

Baris yang salah: baris 3 — nilai_akhir = nilai_uts * 0.4 + nilai_uas * 0.4

Total bobotnya hanya 0,4 + 0,4 = 0,8 (80%), padahal seharusnya 1,0 (100%). Akibatnya nilai_akhir = 32 + 36 = 68, bukan nilai yang sebenarnya.

Perbaikan yang diterima:

nilai_akhir = nilai_uts * 0.5 + nilai_uas * 0.5

atau (kalau ada komponen tugas tambahan):

nilai_akhir = nilai_uts * 0.4 + nilai_uas * 0.4 + nilai_tugas * 0.2

atau bentuk sederhana:

nilai_akhir = (nilai_uts + nilai_uas) / 2

🔴 Level 3 — Tantangan

Skor: 0 / 100

Soal

Buat pseudocode (kode semu) untuk menentukan kategori IMT (Indeks Massa Tubuh), dengan rumus IMT = berat / (tinggi × tinggi).

  • IMT < 18,5 → tampilkan "Kurus"
  • IMT 18,5 – 25 → tampilkan "Normal"
  • IMT > 25 → tampilkan "Gemuk"

Struktur yang harus ada: MULAI → INPUT berat & tinggi → hitung IMT → minimal 2 percabangan JIKA–LAINNYA berurutan → OUTPUT "Kurus"/"Normal"/"Gemuk" → SELESAI.

💡 Petunjuk:

Dibutuhkan lebih dari satu percabangan JIKA–LAINNYA berurutan. Periksa dulu apakah IMT < 18,5. Kalau tidak, periksa lagi apakah IMT <= 25. Kalau dua-duanya tidak, berarti IMT > 25.

📄 Lihat contoh jawaban benar 
MULAI
  INPUT berat, tinggi
  IMT = berat / (tinggi * tinggi)
  JIKA IMT < 18.5 MAKA
    TAMPILKAN "Kurus"
  LAINNYA
    JIKA IMT <= 25 MAKA
      TAMPILKAN "Normal"
    LAINNYA
      TAMPILKAN "Gemuk"
SELESAI
