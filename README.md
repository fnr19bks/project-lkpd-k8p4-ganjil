# LKPD Interaktif — Pseudocode & Debugging — Informatika Kelas 8

Game web statis untuk melatih murid SMP kelas 8 menulis pseudocode dan menemukan *logical error*.  
Dibuat dengan HTML + CSS + JavaScript murni, tanpa backend, tanpa framework, tanpa database.

## Isi Game
- **Level 1 — Pemula:** Menulis pseudocode genap/ganjil.
- **Level 2 — Menengah:** Mengisi tabel tracing dan menemukan bug perhitungan nilai.
- **Level 3 — Tantangan:** Menulis pseudocode kategori IMT dengan percabangan berlapis.
- **Fitur:** Kamus istilah dwibahasa, hint, efek suara, progres tersimpan di localStorage, sertifikat cetak, mode guru (`guru.html`).

## Cara Deploy ke GitHub Pages (Gratis)

1. **Buat akun GitHub**  
   Buka [github.com](https://github.com), klik **Sign up**, isi email, username, dan password.

2. **Buat repository baru**  
   Setelah login, klik tombol hijau **New**. Beri nama `lkpd-pseudocode-k8`, pilih **Public**, klik **Create repository**.

3. **Unggah kelima file**  
   Di halaman repository, klik **Add file → Upload files**.  
   Seret (drag-and-drop) file: `index.html`, `style.css`, `script.js`, `guru.html`, `README.md`.  
   Klik **Commit changes**.

4. **Aktifkan GitHub Pages**  
   Klik tab **Settings** → menu kiri **Pages**.  
   Di bagian **Build and deployment**, pada **Branch** pilih `main` dan folder `/ (root)`.  
   Klik **Save**.

5. **Tunggu 1–3 menit**  
   Refresh halaman Settings → Pages. Akan muncul link seperti:  
   `https://namauser.github.io/lkpd-pseudocode-k8/`  
   Itulah alamat game yang bisa dibagikan ke murid.

6. **Memperbarui game**  
   Buka file yang ingin diubah di GitHub (klik ikon pensil ✏️), edit, lalu klik **Commit changes**.  
   Situs akan otomatis diperbarui dalam beberapa menit.

## Menjalankan Secara Lokal (Tanpa Internet)
1. Simpan kelima file dalam satu folder.
2. Klik dua kali `index.html` — game akan terbuka di browser.
3. Semua fitur berjalan normal kecuali yang membutuhkan server (tidak ada).
