Level 1 — Pemula

Soal: Tulis pseudocode untuk menentukan bilangan genap atau ganjil.

Kunci:

MULAI
  INPUT angka
  sisa = angka mod 2
  JIKA sisa = 0 MAKA
    TAMPILKAN "Genap"
  LAINNYA
    TAMPILKAN "Ganjil"
SELESAI

Kriteria penilaian: MULAI/SELESAI (10), INPUT (20), mod/2 (20), JIKA-LAINNYA (25), Genap/Ganjil (25). Total 100. Lulus ≥ 70.

Level 2 — Menengah

Pseudocode:

MULAI
  INPUT nilai_uts, nilai_uas
  nilai_akhir = nilai_uts * 0.4 + nilai_uas * 0.4
  TAMPILKAN nilai_akhir
SELESAI

Tracing dengan nilai_uts=80, nilai_uas=90:

Bug: Baris 3 — total bobot hanya 0,8 (80%). Seharusnya 1,0 (100%).

Perbaikan yang diterima:

  • nilai_akhir = nilai_uts * 0.5 + nilai_uas * 0.5
  • nilai_akhir = nilai_uts * 0.4 + nilai_uas * 0.4 + nilai_tugas * 0.2
  • nilai_akhir = (nilai_uts + nilai_uas) / 2

Skor: Tracing 40, Bug 30, Perbaikan 30. Total 100. Lulus ≥ 70.

Level 3 — Tantangan

Soal: Pseudocode kategori IMT.

Kunci:

MULAI
  INPUT berat, tinggi
  IMT = berat / (tinggi * tinggi)
  JIKA IMT < 18.5 MAKA
    TAMPILKAN "Kurus"
  LAINNYA
    JIKA IMT <= 25 MAKA
      TAMPILKAN "Normal"
    LAINNYA
      TAMPILKAN "Gemuk"
SELESAI

Skor: Struktur (10), INPUT (15), Rumus (15), Percabangan ≥2 (30), Output lengkap (30). Total 100. Lulus ≥ 70.
